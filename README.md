# AFB Outside Staff TV Dashboard — V2

A polished TV wrapper for the existing AFB Google Sheets dashboard.

## Improvements in V2

- More compact header so the dashboard gets more screen space
- Clear AFB operations title bar
- Live London clock and full date
- Live/offline status indicator
- Countdown to the next five-minute refresh
- Cache-busted iframe reload
- Automatic retry after a slow load
- TV-first full-screen layout
- Logo path simplified to the repository root
